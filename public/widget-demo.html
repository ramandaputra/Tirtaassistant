Simulasi halaman WordPress

Selamat Datang

Ini adalah simulasi halaman WordPress tirtakepri.co.id. Widget chatbot TirtAssistant sudah di-embed di halaman ini menggunakan satu baris script.

Klik tombol chat 💬 di pojok kanan bawah untuk mencoba chatbot.

Cara Embed di WordPress

Cukup tambahkan satu baris ini di WordPress (melalui plugin "Insert Headers and Footers" atau langsung di theme):

<script src="https://tirtassistant.tirtakepri.co.id/widget.js" defer></script>
